# LumaChart — demo reel

Two ~2:14 walkthroughs of the LumaChart prototype (title → 12 feature screens → close).

| File | Audio | Size |
|------|-------|------|
| `LumaChart-demo-voiceover.mp4` | narrated (macOS `say`, on-screen captions) | ~3.3 MB |
| `LumaChart-demo-silent.mp4` | silent (on-screen captions only) | ~1.7 MB |

Both are 1280×800 H.264, under 3 minutes and well under 100 MB.

Rebuild from the current bundle with `bash build_demo.sh` (needs Google Chrome, ffmpeg, and macOS `say`). Frames are captured headless from `../dist/LumaChart.html`; narration and captions are original. Synthetic data only — not for clinical use.
